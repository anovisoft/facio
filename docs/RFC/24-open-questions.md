# Open Questions

Decisions required before / during MVP. Each item should get an owner and a deadline.

## Product

1. **Wedge domain:** fitness skill loops vs fat loss vs cooking vs cessation — which first?
2. **Brand promise:** do we ever say “any goal” in public, or only “goals we support well”?
3. **Custom goals:** reject, second-class scaffold, or waitlist?
4. **Multi-project:** allow from day 1 or force single focus?
5. **Evidence strictness:** self-report only at first, or push optional photo/video?
6. **Tone:** coachy vs managerial vs minimal — what matches brand?
7. **Languages:** RU/EN first? both?

## Taxonomy & content

1. Who is Blueprint Editor #1 for the wedge?
2. What is the numeric quality bar for publishing a blueprint?
3. Synonym policy: when is a new OutcomeType justified vs a tag?
4. How do we handle culturally specific strategies?

## AI / architecture

1. Primary cloud LLM provider + failover?
2. Embedding model choice (multilingual quality vs cost)?
3. MVP vector storage: pgvector vs dedicated?
4. On-device model timeline — never / later / strategic?
5. Patch schema v1 exact ops set?
6. Do we allow any freeform coach answers without tools? (Recommendation: no)

## Safety / legal

1. Entity jurisdiction & ToS/medical disclaimers strategy?
2. Age gate threshold?
3. ED / self-harm response content partners?
4. Insurance / liability appetite for fitness programming?
5. Data retention defaults for transcripts & media?

## Monetization

1. Price points by market?
2. Free Coach allowance exact numbers?
3. Annual vs monthly emphasis?
4. Will expert packs exist in year 1?

## Metrics

1. Exact activation definition?
2. Outcome attainment definitions per first 20 blueprints?
3. What D7/D30 bars kill a blueprint vs iterate?

## Org

1. Build in which mobile stack (already implied by repo — confirm)?
2. Single repo vs content repo split when?
3. Do we need an external domain advisor (PT, RD) on contract?

## Strategic

1. Is Facio eventually cross-domain OS, or a branded vertical that expands carefully?
2. Partnership with human coaches: compete or enable?
3. Name finalization: Facio vs Fasio vs other — trademark check?

---

## Facilitation tip

Run a 90-minute decision workshop on:

- wedge
- custom goal policy
- free vs plus boundary
- safety posture

Do not start wide mobile UI implementation before those four settle.
