# Anti-patterns

## Product anti-patterns

1. **Blank-box home prompt** — trains users to chat, not act.
2. **Interrogation onboarding** — 15 questions before value.
3. **Essay plans** — walls of text nobody executes.
4. **Fake precision progress %** — “47% to marathon.”
5. **Streak hostage** — shame as retention.
6. **Social feed distraction** — competes with execution.
7. **Daily AI pep talk** — cost + notification fatigue + emptiness.
8. **One mega-goal for life** — no micro-project boundaries.
9. **Custom goal escape hatch as default** — silent slide into todo app.
10. **Paywalling today’s task** — trust destruction.

## Architecture anti-patterns

1. **Prompt-as-blueprint** — untestable, expensive, unsafe.
2. **Vector-only understanding** — misses policy & constraints.
3. **Full replan on every miss** — churn + cost.
4. **Transcript-as-source-of-truth** — unqueryable state.
5. **Unbounded coach context** — $ death.
6. **Auto-publish user intents into taxonomy** — garbage-in forever.
7. **Microservice explosion pre-PMF** — ops tax.
8. **Fine-tune first** — delays learning what product is.

## Org anti-patterns

1. Hiring ML researchers before mobile execution quality exists.
2. Marketing “any goal” while supporting twelve.
3. No single owner for outcome attainment metric.
4. Confusing demo wow with retention.

## Rhetorical anti-patterns (pitch)

1. Calling everything a network effect.
2. Moat = “our prompts.”
3. “100k intents” as a substitute for completion rates.

## Replacement patterns

| Anti-pattern | Replace with |
|--------------|--------------|
| Chat home | Next action home |
| Prompt blueprint | Compiled schema blueprint |
| Full replan | Patch ops + playbooks |
| Universal launch | Wedge excellence |
| Engagement north star | Attainment + activation |
