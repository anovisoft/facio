# 06 — Эталоны

Качество среза гоняем на **двух** сценариях. Остальные intents — best-effort.

Общие примитивы; разный default horizon и набор plugins.

---

## A. Карбонара

### Intent (пример)

«Хочу приготовить карбонару»

### Ожидаемый артефакт

| Элемент | Ожидание |
|---------|----------|
| title | Коротко про карбонару / ужин |
| summary | 1–3 предложения: что получится, сколько займёт, логика этапов |
| cycle | Короткий (1 cook_session / один вечер) |
| days | Один день kind=`cook_session` (или эквивалент) |
| groups | Напр. Покупки → Подготовка → Готовка |
| plugins | Checklist на покупки; **TimerStack** на готовке (лапша, мясо/гуанчиале, дробные «помешать») |
| signals | nudge на дробные; alert на критичные («лапша») |
| detail | How-to в шагах готовки, не только заголовки |

### First-run

Batch clarify примерного содержания: на сколько персон, есть ли гуанчиале/панчетта, уровень опыта — **пакетом**, не по одному.

### Live dogfood bar

- Прошли покупки чеклистом
- На готовке реально шли по таймерам (в т.ч. фон)
- Не ощущается «рецепт из ChatGPT в todo»

### Next cycle

Для карбонары less central; опционально «повторить / другой рецепт». Главный next-cycle dogfood — эталон B.

## B. Отжимания → ~30

### Intent (пример)

«Хочу научиться делать 30 отжиманий» / «дойти до 30 отжиманий»

### Ожидаемый артефакт

| Элемент | Ожидание |
|---------|----------|
| title | К 30 отжиманиям / похожий outcome-title |
| summary | Прогноз и смысл **этого** цикла («через ~N недель… эта неделя — база…») |
| cycle | Default **7 дней** (дальше 7/14 по результатам) |
| days | Смесь `train` и `rest` (не 7 одинаковых силовых) |
| plugins | **Counter/Dose** на подходах/повторах; checklist опционален (разминка) |
| day 2 (пример) | rest + лёгкая мобилити — **другой** экран, не «ещё подходы» |

### First-run

Batch: уровень сейчас (сколько отжиманий / с колен), дней в неделю доступно, инвентарь/ограничения — пакетом + comment.

### Live dogfood bar

- Видна карта недели
- День train: крутишь counters, закрываешь сессию
- День rest: не выглядит как пропуск тренировки «по ошибке»
- Хотя бы один repair («не могу сегодня»)
- В конце недели — CTA **Следующий цикл**; N+1 учитывает, что сделано частично/полностью

### Next cycle

```text
Результаты недели (structured)
  + optional batch clarify
  → неделя 2 на базе той же логики программы (объём/дни адаптированы)
```

Copy кнопки может быть «Продолжить тренировки» — жест всё равно детерминированный.

---

## Общий чеклист качества эталона

- [ ] title + summary на create
- [ ] Полная карта на draft с plugins preview
- [ ] Batch clarify без пошагового интервью
- [ ] Live plugins используются, не «для галочки в schema»
- [ ] Разные kind дней различимы
- [ ] Repair доступен
- [ ] (B) next cycle осмыслен

Пока оба эталона не проходят внутренний dogfood — **не** тащим широкий внешний тест.
