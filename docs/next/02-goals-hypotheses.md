# 02 — Цели и гипотезы

## Зачем этот срез

Не проверить «умеет ли LLM строить планы» (это уже POC).

Проверить:

> Становится ли Facio вещью, которой **сами** готовы пользоваться на карбонаре и пути к 30 отжиманиям — с возвратом на следующий день и желанием нажать «следующий цикл»?

Внешний юзер-тест — **после** dogfood-бара, не до (см. [07](./07-testing-stance.md)).

---

## Ядро продукта (next)

```text
Intent
  → Soft-start + полный скелет Path/Cycle (title + summary + дни + plugins)
  → Batch clarify (+ optional comment) → один refine-pass
  → Accept (контракт + live mode)
  → «Сегодня» = день/сессия с исполняемыми плагинами
  → Repair при срыве
  → Конец цикла → детерминированный CTA «следующий цикл»
       → summary результатов + batch уточнения → Cycle N+1
```

---

## Гипотезы

### H1 — Полный Path на draft

Скрытие «настоящего» маршрута до Accept убивает «поняло + уже показывает как».

**Ожидание:** draft показывает полный скелет; Accept = контракт, не «впервые карта».

### H2 — Batch clarify

Один вопрос → пересбор → следующий вопрос ощущается как интервью.

**Ожидание:** 2–4 вопроса + комментарий за один submit; меньше раундов до Accept; Path visibly меняется.

### H3 — Narrative на плане

Без title/summary план = todo. С коротким смыслом в начале — «тренер объяснил».

**Ожидание:** qualitative dogfood — «понятно, к чему идём за цикл», не только список дней.

### H4 — Plugins = ценность wedge

Карбонара без TimerStack и отжимания без Counter — списки, не продукт.

**Ожидание:** на эталонах плагины стоят уже на create (disabled до Accept); в live — ими пользуются, не игнорируют.

### H5 — Cycle + schedule

Плоская очередь не передаёт «день 2 — отдых».

**Ожидание:** Home показывает день цикла и kind; «Весь путь» — карта дней; продление создаёт Cycle N+1, а не бесконечный хвост actions.

### H6 — Детерминированное продление

CTA «следующий цикл» — кнопка продукта; модель может предложить **подпись**, не решение «есть ли кнопка».

**Ожидание:** после завершения (или частичного) цикла жест понятен без чата.

### H7 — Repair must

Без «не могу / сдвинь» цикл умирает к дню 3.

**Ожидание:** хотя бы один repair path используется в dogfood; проект не бросают из-за одного пропуска.

### H8 — Общие примитивы, два эталона

Готовка и тренировки на одних plugins; качество гоняем на карбонаре и отжиманиях, не на «любой intent».

**Ожидание:** оба сценария проходимы end-to-end; прочий intent — best-effort, не блокер среза.

---

## Успех (качественно, до внешних юзеров)

- Автор/команда реально пользуются эталонами несколько дней
- First-run: полный план + batch clarify без ощущения опросника
- «Сегодня» с таймером/каунтером ощущается нужнее, чем заметка
- Есть хотя бы один переход Cycle → Cycle N+1
- Repair спасает срыв, а не только «Пропустить»

## Провал

- Снова «красивый список» без runtime
- Плагины только на Home, на draft их нет (ложный Accept)
- Продление через чат / свободный промпт
- Внешний тест POC и ложный no-go
- Repair отложен «на потом»
