# 03 — UX и потоки

## Главный принцип

> Пользователь никогда не должен думать: «Что делать дальше?»  
> Каждый экран отвечает: **какой следующий шаг сейчас полезен — и почему именно он.**

Два слоя UI:

1. **Сегодня** — один текущий шаг (ежедневный фокус).
2. **Путь** — полный Path: draft сразу после intent, достаточный перед принятием, потом всегда по кнопке.

Нет Chat как главной поверхности.

---

## Словарь UI vs инженерия

| В коде / API / БД | На экране (must) |
|-------------------|------------------|
| `action` | **Сегодня** / **Следующий шаг** (не «Action», не «Задача» как todo) |
| `complete` / Done | **Сделано** |
| `skip` | **Пропустить** / **Не сейчас** |
| `commit` (hard) | **Принять путь** / **Начинаю** |
| soft-start | Короткое «Ок, ведём к этому» — **не** hard Commit |
| `why` | Hero-блок **«Почему сейчас»** |

`Mission` не использовать по умолчанию (пафос на «купить яйца»). При необходимости — точечно для длинных целей.

## Канонический first-run (согласованный flow)

```text
Intent («Что вы хотите сделать?»)
  → Soft-start + comprehension beat
      («Ок — ведём к: {paraphrase цели}»)
  → Сразу: черновик Path (небольшой, но осмысленный)
       + уточняющие вопросы (chips / свой ответ)
  → Пользователь может:
       • ответить → пересобрать draft
       • вернуться на прошлый шаг / доуточнить
       • открыть/развернуть путь
  → Когда Path устраивает: достаточный полный Path
       + контракт (успех, горизонт, нагрузка)
       + Hard Commit («Принять путь» / «Начинаю» + когда первый шаг)
  → Project Home: Сегодня + «Почему сейчас» + «Весь путь»
  → Сделано → First Completion → следующий шаг
```

**Не делаем:** единственный Commit *до* clarify/generate (пустое обещание без маршрута).  
**Делаем:** эмоциональный soft-start сразу; контрактный Commit — после устраивающего Path.

---

## First-run «поняло цель» (emotion beat)

После intent, до ощущения «опросник»:

1. Короткий paraphrase цели словами пользователя / ясным outcome.  
2. Сразу виден draft Path — не пустой экран вопросов.  
3. Уточнения выглядят как улучшение пути, не как интервью для доступа.

Вау = «оно поняло + уже показывает как», не слоган ради слогана.

## Экраны

1. **Projects** — список active/draft; новый intent  
2. **Intent** — поле + примеры  
3. **Draft studio** — soft-start + draft Path + clarify (назад/вперёд/пересбор)  
4. **Accept** — полный Path + контракт + **Принять путь**  
5. **Project Home** — Сегодня + Почему сейчас + Весь путь  
6. **Path** — полный список, detail, статусы  
7. **History** (secondary)

---

## Happy path (сжато)

```text
Intent
  → soft-start + draft Path + questions
  → refine loop (назад / свой ответ / пересбор)
  → Accept (полный Path + Commit)
  → Сегодня / Сделано / …
```

Multi-project: тот же flow на каждый; список показывает текущий шаг каждого.

## Abort / refine

- Ушёл до Accept → `draft`, можно вернуться  
- «Изменить ответы» / назад → новый LLM snapshot в `state_versions`  
- Skip → лог; Path помечает шаг  

## Repair

```text
Проект → «Не могу / сдвинуть»
  → shift или recompute
  → новый snapshot + новый «Сегодня»
```

## Draft studio (layout)

```text
Ок — ведём к: {paraphrase}

Черновик пути
─────────────
1. …
2. …
[ развернуть ]

Чтобы путь был точнее:
{вопрос}
[ вариант ] [ вариант ] [ свой ответ ]

[ Назад ]  [ Обновить путь ]
```

Перед Accept draft может укоротиться; **перед Commit** Path должен быть достаточным (готовка: и продукты, и как готовить).

---

## Accept (layout)

```text
Цель: {outcome}
Успех: {success_criteria}
Горизонт / нагрузка: …

Весь путь
──────────
1. … (detail)
2. …
…

Когда первый шаг: [сегодня] [завтра] …

[ Принять путь ]   [ Ещё уточнить ]
```

---

## Project Home (layout) — why как hero

```text
Проекты › {outcome short}

Сегодня
────────
{title}
~{estimate_min} мин

Почему сейчас          ← hero, не grey footnote
────────────────────
{why}

[ Сделано ]   [ Пропустить ]

[ Весь путь ]
```

Правило: пустой `why` в schema = validation fail / retry. Без «Почему сейчас» экран не считается готовым.

Для карбонары и т.п. в Path и в `detail` шага — how-to, не только заголовок.

---

## Multi-project

- N active — must  
- Новый intent не закрывает другие  
- (Should) мягкий «фокус сегодня»  

---

## First Completion

- Первый **Сделано** по проекту  
- Коротко «вы в деле» → сразу следующий «Сегодня»  
- Без токсичных streak  

---

## Чего не должно быть

- Home = чат  
- Hard Commit до показа Path  
- Path недоступен после старта  
- Кнопки «Done» / «Action» в пользовательском copy  
- `why` спрятан мелким шрифтом  
- Paywall до первого Сделано  
- Single-active only
