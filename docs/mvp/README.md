# Facio MVP

Документы этого каталога фиксируют **продуктовый эксперимент**, а не целевую архитектуру из `RFC/`.

RFC описывает, к чему система может вырасти.  
MVP проверяет, есть ли у Facio право на жизнь.

Спека намеренно «правильный» execution engine **плюс** first-run emotion beat («поняло цель»), а не вместо него.

## Одно предложение

> Facio сразу показывает, что понял цель (draft Path + уточнения), даёт **принять путь**, ведёт несколько проектов через ежедневное **«Сегодня»** с блоком **«Почему сейчас»**, полный Path — всегда под рукой; всё логируется для обучения.

Центр: уменьшить неопределённость («что дальше и почему»). Не чат. В UI нет слова Action/Done — есть **Сегодня** / **Сделано**.
