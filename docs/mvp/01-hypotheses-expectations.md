# 01 — Гипотезы и ожидания

## Зачем этот MVP

Не проверить, «умеет ли AI строить планы».

Проверить:

> Нужен ли людям продукт, который сразу даёт ощущение «поняло мою цель», превращает «я хочу» в **принятый путь** и ежедневное **«Сегодня» с «Почему сейчас»**, и заставляет возвращаться — не за чатом, а за следующим шагом.

Спека = сильный execution engine **и** first-run emotion beat. «Слишком правильно» без вау первого запуска — недоработка UX, не повод выкидывать engine.

---

## Ядро продукта

```text
Intent
  → Soft-start («поняло цель») + draft Path + уточнения
  → Hard Commit («Принять путь»)
  → First «Сделано»
  → Следующее «Сегодня»
  → возврат завтра
```

Минимальные единицы:

1. **Soft-start** — эмоционально «уже ведём» (не контракт)  
2. **Hard Commit** — «принимаю этот путь» после достаточного Path  
3. **Сегодня** — один текущий шаг + **Почему сейчас**  
4. **First Completion** — первое «Сделано» → тип пользователя «исполняющий»

Полный Path — first-class на draft, на Accept и по кнопке после старта.

---

## Гипотезы

### H1 — «Поняло цель» на first-run

Paraphrase + сразу draft Path сильнее карточек и сильнее голого опросника.

**Ожидание:** в фидбеке «оно поняло», не «заполнил форму».

### H2 — Soft-start ≠ Hard Commit

Эмоциональный старт сразу; **Принять путь** — только после устраивающего Path.

**Ожидание:** Commit до Path как единственный жест — **не** используем; draft→refine→Accept повышает качество commitment.

### H3 — Refine loop до Accept

Назад / chips / свой ответ / пересбор снижают «план мимо» и повышают Commit rate.

**Ожидание:** часть пользователей делает ≥1 refine; commit после refine не ниже, чем one-shot.

### H4 — Сегодня + Почему сейчас + Path

Default Home — один шаг; `why` — hero; Path всегда доступен (критично для готовки).

**Ожидание:** FCT короткий; Path на generate/accept показываем сами; revisit Path — норма.

### H5 — First «Сделано» важнее красивого текста

**Ожидание:** same-day first complete у заметной доли committed; second &lt; 48h.

### H6 — Возврат ради «Сегодня», не ради чата

**Ожидание:** нет chat-вкладки; D1 open к текущему шагу.

### H7 — LLM на create / редкий repair

**Ожидание:** daily loop без токенов; cost информативен.

### H8 — Multi-active

**Ожидание:** ≥2 projects у части users; смотреть FCT/return vs single.

### H9 — Audit trail

**Ожидание:** каждый create/repair с raw llm + state_version.

### H10 — UI-словарь меняет восприятие

«Сегодня» / «Сделано» / «Почему сейчас» ≠ Todoist.

**Ожидание:** qualitative — не называют «тасками».

## Успех (качественно)

- Intent → soft-start → refine → Accept работает без путаницы  
- Same-day first «Сделано», возвраты на D1  
- «Поняло» + «понятно почему сегодня» + для рецептов «вижу как готовить»  
- Demand по доменам для wedge  

Пороги: `04-metrics.md`, `06-go-nogo.md`.

---

## Провал

- Много draft Path, мало Accept / мало «Сделано»  
- FCT днями  
- Home = только чтение Path без шагов  
- Просят чат, игнорируют «Сделано»  
- Дыры в llm/state логах  
- Hard Commit без Path как основной flow (если вдруг вернём — регрессия)
