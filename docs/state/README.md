**Этот каталог не заменяет RFC.** Здесь только стек, инварианты, порядок работ и «где мы сейчас». Если решение меняет продукт — сначала правится RFC, потом эта папка.

## Мины, которые саммари сожмёт

- RFC не переписывать. Eng-правда только здесь. Архив и Expo не воскрешать.
- Закон общий: Swift гоняет `packages/domain/fixtures`. Расхождение — дыра релиза. Посев на Сегодня; в фикстурах те же id лежат в Lifetime — так и должно быть.
- Живая подсказка на отжиманиях: «держи корпус и ягодицы», не английская лекция из фикстуры.
- Лесной зелёный из Expo — запрещён как акцент. `AccentColor` системный.
- Тема следует системе. Светлая атмосфера + dark = белый текст на светлом и моргание шторки. Атмосфера — слабый градиент (не плоская заливка) в `containerBackground(for: .navigation)` плюс копия за стек; `.allowsHitTesting(false)`. Не класть как `.background()` на `NavigationStack`: непрозрачный хром (моноцвет) и мёртвый первый запуск (пустой фон или UI без хитов). Склад через `@State` factory (`DeskStore.live()`), не создавать в `App.init`.
- Liquid Glass включён. Стекло без пятен на фоне не читается. **`GlassEffectContainer` только для кучки кнопок Use (−/+).** На крышке каждая плитка со своим стеклом: общий контейнер сливает ряд велосипеда и два квадрата в одну T-кляксу.
- Плитка: весь квадрат открывает Use (`contentShape` на `.plain`). Галочка на крышке — символ 36pt **overlay рядом** с `FacioTileButton`, не `Button` внутри кнопки (тап молчит или срабатывает дважды). Стекло на стекле снаружи делает круг невидимым. Soon / Postponed — без живых тиков; тап → **Inspect**, не Use.
- Use счётчика: − / + / Готово всегда на месте (стеклянная капсула, не подпись). Готовый случай плюс/минус возвращает в running. Use галочки — символ 44pt, не круг-герой.
- Use: системный бар, не прятать back. Свайп от края = назад. Свайп в другой день посреди подхода запрещён. Кастомное «Назад» + `navigationBarBackButtonHidden` убивает жест.
- Напоминание: час из окна, не из модели. «зал до 22» → `window_from_closing` → 19:00. Пуш локальный, тап → крышка, не Use. **`opens_at` в схему не добавлять**; пол пикера 06:00…`closes_at`.
- Use часа (принято PO): чип «успеть к 19:00» из склада + `@State` после сейва. Тап → нижний sheet ~340pt, колёса 128×196, **Сохранить** у нижнего края, без заголовка в sheet, фон системный. «Готово» на Use закрывает случай, не пикер. Нельзя: `DatePicker` (binding мёртвый / `.constant` не обновляется), `.disabled` (серый, без хита), `.clipped` на колесе (selection остаётся 19:00), `.fitted` (fullscreen), `.medium` / пустой 320 (дыра), второй `AtmosphereBackground` в sheet, inline-колесо под текстом. Писать `ClockTime` из `@Observable` draft колбэком родителя. Склад — один `commit` (`snapshot = next`). **`generation` удалён, не возвращать.** Окно субъекта пишется и после done.
- Плитка велосипеда как остальные: кебаб, заголовок `.primary`. Слот **4×2** (`wide`), не banner 4×1 — ряд в одну клетку заезжает на соседа. Старый `4x1` поднимает `ensureBike`. Плитки клипаются по слоту пака.
- Крышку, тему и рот не отдавать ферме. В Task вписывать скилы по имени.
- Полир только по списку PO. Клин UI принят как гипотеза. План волн В1–В3 принят PO (2026-08-20). **В1.4 принят PO**; микро UI не чинить, пока PO не даст список. **В1.5 harness:** `pytest -m live` / `--live`; обычный pytest не бьёт в вендора. Код — текущий шаг (промпт после live 3/8), не В2.
- Карточка срыва (принято PO): не Use и не кебаб. Чипы только вниз: сегодня / раз в неделю / убрать. Не «постарайся». Пока карточка на экране, плитки этого субъекта прячутся. `stop` не рисуем. Ответ один раз на период ритма (`driftAskedAt`). Чипы внутри стекла плитки — системные капсулы, не glass-on-glass. Высота 32, ширина по тексту до 152, дальше многоточие; ряд переносится. Нельзя: `maxWidth: .infinity`, `.controlSize(.large)`, равная ширина на всю карточку (текст режется, кнопки на полкарточки). `visibleToday` не должен звать хелпер, который снова читает `visibleToday` — бесконечная рекурсия, краш при старте.
- **В1.4 `applyTalk`:** полная подмена стола откатывала running count. Клиент декодирует `tool_calls`. Локальный `.running` `payload.count` сохраняется, пока успешный `update_widget` / `create_widget` не назвал этот виджет (`widget_id` / `id`). `commit(reminders: true)` как раньше. Док не трогать.
- Рот (принято PO, 2026-08-19): док внизу крышки и Use (PO). `facioComposerDock()` на LidScreen и UseScreen, не на NavigationStack — иначе «Готово» под доком. **На Inspect дока нет.** Тап → лист ~0.94 экрана, ручка свернуть. Свернуть ≠ новый тред. «Новый чат» справа сверху листа. Плейсхолдер «Что сюда на стол?», не «спроси что угодно». Поле листа — однострочный `TextField` по вертикальному центру капсулы (рядом с кнопкой 32pt). Не `axis: .vertical`: UITextView сажает заглушку ниже середины. Справа от поля пустой слот 44pt под голос — кнопки нет. Пузыри: человек справа, рот слева, снимок виджета по центру (картинка, не рантайм). Тап снимка → Use. Схема сменилась → живая плитка + снимок; только объяснение → текст. Ключ модели на сервере; клиент бьёт в `FacioTalkURL` (`http://127.0.0.1:8000`). Нет трубы → «Разговор сейчас без трубы. Крышка работает.» Крышка без сервиса тикает. Логи симулятора (`TUIPredictionViewCell`, `_UIRemoteKeyboards`, `linguisticdata`, `Invalidated by remote connection`) — шум клавиатуры, не труба. Нельзя: Atmosphere в talk sheet, новый тред при collapse, `generation`, чат-дом вместо крышки. Список Talks — **сковородка**, не лист рта.
- Сковородка (шаг 5, **принят PO на минималках**, 2026-08-19). Только с корня крышки: ☰ + жёлоб ~20pt на `LidScreen` (не на стеке, не на Use/Inspect). Клавиатура вверх — жест выкл. На Use/Inspect левый край = системный назад. Содержимое: Разговоры (архив → `TalkStore.open` в лист), Практики / Deeds (ритм + как держится → кебаб), Настройки — подпись «позже». Не складывать второй склад виджетов в шторку.
  - Крышка при открытой шторке — **карточка на всю высоту**. `PanSlideLayout` **кладёт** крышку в `x = revealed` размером **контейнера** (`PanSlideLaw.lidFrame`). Закрыто (`revealed == 0`) — крышка = весь экран. Нельзя: `HStack` + `offset(-ширинаШторки)` (запуск/Use в левой половине или крышка сжата до ~60%); `GeometryReader` вокруг `NavigationStack`; ширина крышки из `UIScreen` (`WindowMetrics.width` только для *ширины шторки*); `zIndex` шторки выше крышки (текст поверх карточки при закрытии).
  - «Facio» — `.largeTitle` **в ленте** с `pagePadding`, как плитки. `facioLidTitle()` держит `navigationTitle` + `.inline` + пустой `principal` — только чтобы Use показал back «Facio». Нельзя: `safeAreaPadding(.leading)` на стеке/`LidScreen`/`restoredLeading` — бар обнуляет inset, липнет вся лента; док жив, у него свой padding.
  - Dim **всегда на крышке**, `opacity` по progress. Нельзя `if revealed > 0` — слой снимается и гаснет на месте, пока крышка едет.
  - Шторка под `ignoresSafeArea()`: `.safeAreaPadding(.top)` — no-op; верх/низ = `WindowMetrics.safeArea`. Скругление `WindowMetrics.displayCornerRadius` (0 когда закрыта). `generation` не возвращать.
  - Кебаб урезан — PO сказал ок на сейчас: чипы случаев, Открыть → Inspect, миниатюра «разговор ещё не начинался». Postpone/delete и живая 3×4 миниатюра чата **не делать**, пока PO не попросит. Зажатие плитки (~0.45s, `LongPressTapLock`) открывает тот же инспектор; короткий тап не должен открыть Use следом. `facioKebab` — overlay-sibling, не `Button` внутри плитки. Карточка срыва без кебаба.
  - Inspect ≠ Use. Дата громкая, чипы (не полноэкранный `TabView` — бьётся с жестом назад), без −/+/Готово. Док рта на Inspect нет. Плюс → `addInstance`: Сегодня занято (ready/running или done сегодня) — клон плитки; иначе перепривязка standing/Lifetime (велосипед). Done сегодня не переписывать.
- Рефактор шага 5 (2026-08-19): геометрия в `PanSlideLaw`; окно в `WindowMetrics`; «Facio» в `facioLidTitle()`; кебаб→рот через `sheet(onDismiss:)`, без sleep; `LongPressTapLock` оставлен — `@State` опоздал бы к тапу. Несущие: пустой `principal`, `compositingGroup` на карточке крышки, UIKit окно, клавиатура в `PanHost`, две атмосферы. Не воскрешать отвергнутые вёрстки шторки.
- Золотые (`apps/api/goldens`): founding три не трогать: «поясница забирает» → `add_cue` do-time на push-ups (**«держи корпус и ягодицы, не поясницу»** — иначе плитка на записи не меняется); «больно, давай 40» → цель остаётся 30; «что значит держать корпус» → текст, без карточки. В1.2: `method_4_to_30`, `gym_no_clock` («запиши зал»), `miss_skip` («сегодня не сходил»), `remind_at_19`, `gym_until_22`, `cadence_shrink`. Неизвестное («квэкснутый зонд 174») — без патча. `match_golden` = первый отсортированный файл; иглы не пересекать. Режим по умолчанию `scripted`. Боль **до** инструментов. `add_cue` без `surface` — отказ. Патч — проверенный `Desk`.
- Живая модель: `FACIO_MODEL_NAME` выбирает ключ. `gpt-4o-mini` / `gpt` → OpenAI (`FACIO_OPENAI_API_KEY`). `haiku` / `claude-haiku` / `claude-haiku-4-5` → Anthropic Haiku (`FACIO_ANTHROPIC_API_KEY`). Оба ключа необязательны; в `live` без ключа выбранного вендора — 503, не молчаливый scripted. Чужой ключ не подставлять (Haiku не ходит в OpenAI, даже если GPT-ключ заполнен). `FACIO_MODEL_API_KEY` больше нет. Gemini и прочие вендоры — не этот шаг.
- Труба гоняется Compose из корня: `docker compose up --build`, сервис `talk`, порт 8000. Контекст сборки — корень (нужны `packages/domain` + `apps/api`). **Postgres в этот compose не класть** — архивный `archive/docker-compose.yml` не копировать. Золотые в контейнере: `FACIO_GOLDENS_DIR=/app/apps/api/goldens`. Нужен запущенный Docker Desktop. `fastapi dev` без `fastapi[standard]` падает (`RuntimeError` про `pip install "fastapi[standard]"`) — в `apps/api` зависимость уже `fastapi[standard]>=0.115`. `.env` в корне или `apps/api/.env`; в образ не копировать.
- `ensureDrift` дописывает `bike-silent` (21 день) **только** если у велосипеда не было completed/in_progress. Живую активность не подменять. Плитку с Today на Lifetime двигает только этот первый посев.
- Убранный субъект не даёт пуш. Инстансы и подсказки не удалять.
- Движок утренней дельты и утренний пуш — не этот шаг. Не выдумывать час.
- Пуши только через `ReminderScheduler.enqueue` (запуск в `RootView` тоже). `sync` не публичный — обход gate воскрешает закрытый будильник. Enqueue только когда меняется напоминание, не на −/+. Перекрывающиеся sync сливаются.
- `markCueSurfaced` один раз на виджет+место+день. Ключи дня из `journal.jsonl` при старте; RAM мало — холодный старт крутил hits. `onAppear` плитки при скролле не инкрементирует.
- `ensureBike` дописывает `window`, если `bike` есть без окна, **и** выравнивает `fireAt` / `when` виджета (и незакрытого случая). Иначе чип 19:00, пуш со старого часа.
- Закон кладёт карточку срыва в `projection.today`; крышка её рисует. «ничего на сегодня — и это нормально» только если **видимый** Сегодня пуст (карточка считается). Секции Lifetime / Soon / Postponed: сначала `WidgetType.showsOnLid`, без retired, без субъекта живой карточки. Заголовок только при непустом видимом списке. `tileCellSize` только у counter / tick / reminder — `EmptyView`+размер занимает клетку.
- Версия: `MARKETING_VERSION` `0.1.0` в `project.yml`; `Info.plist` берёт `$(MARKETING_VERSION)`, не зашивать `1.0`.
- Клин UI принят как гипотеза (PO, 2026-08-19 вечер). План волн **В1–В3** принят PO (2026-08-20). Р.1–Р.5 сняты. **В1.0–В1.4 готовы. В1.4 принят PO**: микро UI — **парковка**. **В1.5 harness готов**; live 3/8, промпт не крутили. Не оставлять ход в пяти файлах. `fastapi-templates` не копировать в В1–В2; **в В3 можно** (сессия БД, репозитории стола/аккаунта), закон остаётся в `facio_domain`. Зал/практика из рта сначала **без** напоминания; час — после пропуска или «напомни в 19, в 21 сплю» (`latest_by` как сказано, не 21−3ч). «зал до 22» по-прежнему 19:00, только если факт произнесли. Посев велосипеда с 19:00 не ломаем. MCP — обёртка в том же `apps/api`; телефон HTTP. RAG корпуса спорта нет; поиск по своим фактам — В3. Календарь 7 дней — Inspect, не крышка. Заморозка + локальный чек-ин — В2; облачный пуш — В3. **Вход (PO 2026-08-20):** Sign in with Apple в В3; крышка без логина в В1–В2; Google до второй платформы не делать. Device-id не воскрешать.

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.

## Как обновлять

Писать сюда, когда принят/отвергнут шаг, поймана мина, сдвинут вопрос RFC (тогда ещё `docs/rfc/07`), сменилось «что дальше». Не писать полир и вторую копию RFC.
