# Состояние реализации Facio

Рабочая память для кода и новых сессий.  
Продуктовая правда — [`docs/rfc/`](../rfc/README.md) (черновик v0.7). Сюда RFC не копируем и не раздуваем.

**Этот каталог не заменяет RFC.** Здесь только инженерные выводы, порядок работ и «где мы сейчас». Если решение меняет продукт — сначала правится RFC, потом эта папка.

Зафиксировано перед суммаризацией сессии 2026-08-15.

## После суммаризации — начать здесь

1. Этот файл целиком.
2. [Решения](./decisions.md) — инварианты, рот, мины dogfood.
3. [План](./plan.md) — шаги 0–3 приняты; 4 труба есть, поверхность отвергнута.
4. [Идентичность](./identity.md) — не выдумывать bundle / slug / team.
5. По задаче — RFC: [00](../rfc/00-vision.md) … [07](../rfc/07-open-questions.md).

Не эволюционировать `archive/apps`. Новый код: `apps/mobile`, `apps/api`, `packages/domain`.

**Роли.** PO = человек. PM = ведущий агент этого чата, **код не пишет**. Разработчики = субагенты, модель **Grok 4.6 High Fast** (`cursor-grok-4.6-high-fast`). Цикл: PM формулирует шаг → субагент делает → PO dogfood → фидбек → правка или следующий шаг. Перед суммаризацией PM снова пишет сюда.

**Следующее действие.** Ждёт указания PO. Следующий экранный шаг, когда скажет: рот — инпут всегда внизу на крышке и в Use, тап → чат почти на весь экран, свайп скрывает. Не «затянуть поле под Готово». Не полный мессенджер сразу, если PO не попросит целиком.

## Как гонять

```bash
# API
cp .env.example .env          # ANTHROPIC_API_KEY
docker compose up --build
# или uvicorn из apps/api, порт 8000

# Телефон
cd apps/mobile
cp .env.example .env          # EXPO_PUBLIC_API_URL=http://localhost:8000
# живой телефон: IP мака, не localhost
npx expo prebuild --platform ios && npm run ios
```

`EXPO_PUBLIC_*` вшивается при старте Metro — после смены `.env` перезапустить бандлер. Без URL в Use будет «нет адреса сервиса». Без ключа на API — 501, стол не портится.

Идентичность: `Facio` / `facio` / `com.anovisoft.facio` / team `SXXLPXXJMD` + плагин `withAppleTeamId`.

## Мины, которые саммари потеряет

- Готовые отжимания когда-то уезжали в Lifetime и прикидывались живыми. Больше не надо. Повтор — плюс позже (шаг 5), не второе Готово.
- Ложный `running` после взгляда в Use ломал сетку на [2×2]/[4×1]/[2×2]. Не чинить упаковщиком.
- «Срыв как 8 дней» в модалке «когда напомнить» — не продукт. После «Убрать» не снимало отставку. Проверки только с Facio (долгий тап); модалка = час и Сохранить. В Use велосипеда можно «напомнить через минуту» без жаргона.
- Узкий write затопил founding cue лекцией на английском («shoulders packed…») и обрезанным «let's reinforce». Do-time должен быть короткой командой на языке человека. Последний do-time сейчас побеждает на плитке — лекцию нельзя класть поверх «держи корпус».
- RFC: на Use чата нет. PO: рот есть и на Use. Когда строить чат — слушаем PO, не старый запрет.
- Склад живой: `seedIfEmpty` не перезатирает. Велосипед и founding-silence досеваются. Чтобы вернуть посев — удалить приложение.
- Архивный `archive/docker-compose.yml` (Postgres + Path) не использовать для rewrite.

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
