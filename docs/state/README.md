# Состояние реализации Facio

Рабочая память для кода и новых сессий.  
Продуктовая правда — [`docs/rfc/`](../rfc/README.md) (черновик v0.7). Сюда RFC не копируем и не раздуваем.

**Этот каталог не заменяет RFC.** Здесь только инженерные выводы, порядок работ и «где мы сейчас». Если решение меняет продукт — сначала правится RFC, потом эта папка.

---

## Новая сессия — читать в таком порядке

1. Этот файл (снимок ниже).
2. [Решения](./decisions.md) — что уже зафиксировано, чего не делать.
3. [План](./plan.md) — шаги, клин на двое суток, критерии остановки.
4. По задаче — нужный файл из RFC: [00 зрение](../rfc/00-vision.md), [03 продукт](../rfc/03-product.md), [04 модель](../rfc/04-domain-model.md), [05 ИИ](../rfc/05-ai-and-memory.md), [06 никогда](../rfc/06-never-do.md), [07 открытое](../rfc/07-open-questions.md).

Старый код и старые RFC — только справка: [`archive/`](../../archive/). Не эволюционировать `archive/apps` в новый продукт.

## Снимок (2026-08-15)

| Слой | Состояние |
|------|-----------|
| Продукт | RFC v0.7 принят как день-за-днём правда. Центр: практика (ритм + окно + подсказки + расчётный срыв). |
| Код rewrite | Ещё нет. Репозиторий = RFC + архив 0.1. |
| Инженерный план | Зафиксирован в этой папке. Не открывать полный чат и сервер, пока не живёт клин. |
| Следующее действие | Собрать клин на двое суток (см. [план](./plan.md)): крышка, подсказка на плитке, срыв, правка руками и узкий разговор. |

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.

---

## Как обновлять эту папку

Писать сюда, когда:

- принят или отвергнут шаг плана;
- поймана мина, которую саммари чата потеряет;
- закрыт или сдвинут вопрос из RFC (тогда ещё правка `docs/rfc/07-open-questions.md`);
- сменилось «следующее действие».

Не писать сюда визуальный полир, тикеты на будущее и вторую копию RFC.
