## Мины, которые саммари сожмёт

- RFC не переписывать. Eng-правда только здесь. Архив и Expo не воскрешать.
- Закон общий: Swift гоняет `packages/domain/fixtures`. Расхождение — дыра релиза. Посев на Сегодня; в фикстурах те же id лежат в Lifetime — так и должно быть.
- Живая подсказка на отжиманиях: «держи корпус и ягодицы», не английская лекция из фикстуры.
- Лесной зелёный из Expo — запрещён как акцент. `AccentColor` системный.
- Тема следует системе. Светлая атмосфера + dark = белый текст на светлом и моргание шторки. Атмосфера — слабый градиент (не плоская заливка) в `containerBackground(for: .navigation)` плюс копия за стек; `.allowsHitTesting(false)`. Не класть как `.background()` на `NavigationStack`: непрозрачный хром (моноцвет) и мёртвый первый запуск (пустой фон или UI без хитов). Склад через `@State` factory (`DeskStore.live()`), не создавать в `App.init`.
- Liquid Glass включён. Стекло без пятен на фоне не читается. **`GlassEffectContainer` только для кучки кнопок Use (−/+).** На крышке каждая плитка со своим стеклом: общий контейнер сливает ряд велосипеда и два квадрата в одну T-кляксу.
- Плитка: весь квадрат открывает Use (`contentShape` на `.plain`). Галочка на крышке — символ 36pt **внутри** плитки. Стекло на стекле снаружи делает круг невидимым.
- Use счётчика: − / + / Готово всегда на месте (стеклянная капсула, не подпись). Готовый случай плюс/минус возвращает в running. Use галочки — символ 44pt, не круг-герой.
- Use: системный бар, не прятать back. Свайп от края = назад. Свайп в другой день посреди подхода запрещён. Кастомное «Назад» + `navigationBarBackButtonHidden` убивает жест.
- Напоминание: час из окна, не из модели. «зал до 22» → `window_from_closing` → 19:00. Пуш локальный, тап → крышка, не Use. **`opens_at` в схему не добавлять**; пол пикера 06:00…`closes_at`.
- Use часа (принято PO): чип «успеть к 19:00» из склада + `@State` после сейва. Тап → нижний sheet ~340pt, колёса 128×196, **Сохранить** у нижнего края, без заголовка в sheet, фон системный. «Готово» на Use закрывает случай, не пикер. Нельзя: `DatePicker` (binding мёртвый / `.constant` не обновляется), `.disabled` (серый, без хита), `.clipped` на колесе (selection остаётся 19:00), `.fitted` (fullscreen), `.medium` / пустой 320 (дыра), второй `AtmosphereBackground` в sheet, inline-колесо под текстом. Писать `ClockTime` из `@Observable` draft колбэком родителя. `editReminderLatestBy` заменяет весь `snapshot` (`generation++`); окно субъекта пишется и после done.
- Плитка велосипеда как остальные: кебаб, заголовок `.primary`. Слот **4×2** (`wide`), не banner 4×1 — ряд в одну клетку заезжает на соседа. Старый `4x1` поднимает `ensureBike`. Плитки клипаются по слоту пака.
- Крышку, тему и рот не отдавать ферме. В Task вписывать скилы по имени.
- Рот — часть клина (витрина + чужой человек), но не вместо шага 3 и не пока PO не скажет начать.
- Полир только по списку PO. Шаг 2 закрыт; шаг 3 не начинать самовольно.

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
