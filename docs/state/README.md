**Этот каталог не заменяет RFC.** Здесь только стек, инварианты, порядок работ и «где мы сейчас». Если решение меняет продукт — сначала правится RFC, потом эта папка.

## Мины, которые саммари сожмёт

- RFC не переписывать. Eng-правда только здесь. Архив и Expo не воскрешать.
- Закон общий: Swift гоняет `packages/domain/fixtures`. Расхождение — дыра релиза. Посев на Сегодня; в фикстурах те же id лежат в Lifetime — так и должно быть.
- Живая подсказка на отжиманиях: «держи корпус и ягодицы», не английская лекция из фикстуры.
- Лесной зелёный из Expo — запрещён как акцент. `AccentColor` системный.
- Тема следует системе. Светлая атмосфера + dark = белый текст на светлом и моргание шторки. Атмосфера — слабый градиент (не плоская заливка) в `containerBackground(for: .navigation)` плюс копия за стек; `.allowsHitTesting(false)`. Не класть как `.background()` на `NavigationStack`: непрозрачный хром (моноцвет) и мёртвый первый запуск (пустой фон или UI без хитов). Склад через `@State` factory (`DeskStore.live()`), не создавать в `App.init`.
- Liquid Glass включён. Стекло без пятен на фоне не читается. **`GlassEffectContainer` только для кучки кнопок Use (−/+).** На крышке каждая плитка со своим стеклом: общий контейнер сливает ряд велосипеда и два квадрата в одну T-кляксу.
- Плитка: весь квадрат открывает Use (`contentShape` на `.plain`). Галочка на крышке — символ 36pt **overlay рядом** с `FacioTileButton`, не `Button` внутри кнопки (тап молчит или срабатывает дважды). Стекло на стекле снаружи делает круг невидимым. Soon / Postponed — glance-only (`action: nil`).
- Use счётчика: − / + / Готово всегда на месте (стеклянная капсула, не подпись). Готовый случай плюс/минус возвращает в running. Use галочки — символ 44pt, не круг-герой.
- Use: системный бар, не прятать back. Свайп от края = назад. Свайп в другой день посреди подхода запрещён. Кастомное «Назад» + `navigationBarBackButtonHidden` убивает жест.
- Напоминание: час из окна, не из модели. «зал до 22» → `window_from_closing` → 19:00. Пуш локальный, тап → крышка, не Use. **`opens_at` в схему не добавлять**; пол пикера 06:00…`closes_at`.
- Use часа (принято PO): чип «успеть к 19:00» из склада + `@State` после сейва. Тап → нижний sheet ~340pt, колёса 128×196, **Сохранить** у нижнего края, без заголовка в sheet, фон системный. «Готово» на Use закрывает случай, не пикер. Нельзя: `DatePicker` (binding мёртвый / `.constant` не обновляется), `.disabled` (серый, без хита), `.clipped` на колесе (selection остаётся 19:00), `.fitted` (fullscreen), `.medium` / пустой 320 (дыра), второй `AtmosphereBackground` в sheet, inline-колесо под текстом. Писать `ClockTime` из `@Observable` draft колбэком родителя. Склад — один `commit` (`snapshot = next`). **`generation` удалён, не возвращать.** Окно субъекта пишется и после done.
- Плитка велосипеда как остальные: кебаб, заголовок `.primary`. Слот **4×2** (`wide`), не banner 4×1 — ряд в одну клетку заезжает на соседа. Старый `4x1` поднимает `ensureBike`. Плитки клипаются по слоту пака.
- Крышку, тему и рот не отдавать ферме. В Task вписывать скилы по имени.
- Рот — часть клина (витрина + чужой человек), но не вместо шага 4 и не пока PO не скажет начать.
- Полир только по списку PO. Шаг 3 закрыт; шаг 4 не начинать самовольно.
- Карточка срыва (принято PO): не Use и не кебаб. Чипы только вниз: сегодня / раз в неделю / убрать. Не «постарайся». Пока карточка на экране, плитки этого субъекта прячутся. `stop` не рисуем. Ответ один раз на период ритма (`driftAskedAt`). Чипы внутри стекла плитки — системные капсулы, не glass-on-glass. Высота 32, ширина по тексту до 152, дальше многоточие; ряд переносится. Нельзя: `maxWidth: .infinity`, `.controlSize(.large)`, равная ширина на всю карточку (текст режется, кнопки на полкарточки). `visibleToday` не должен звать хелпер, который снова читает `visibleToday` — бесконечная рекурсия, краш при старте.
- `ensureDrift` дописывает `bike-silent` (21 день) **только** если у велосипеда не было completed/in_progress. Живую активность не подменять. Плитку с Today на Lifetime двигает только этот первый посев.
- Убранный субъект не даёт пуш. Инстансы и подсказки не удалять.
- Движок утренней дельты и утренний пуш — не этот шаг. Не выдумывать час.
- Пуши только через `ReminderScheduler.enqueue` (запуск в `RootView` тоже). `sync` не публичный — обход gate воскрешает закрытый будильник. Enqueue только когда меняется напоминание, не на −/+. Перекрывающиеся sync сливаются.
- `markCueSurfaced` один раз на виджет+место+день. Ключи дня из `journal.jsonl` при старте; RAM мало — холодный старт крутил hits. `onAppear` плитки при скролле не инкрементирует.
- `ensureBike` дописывает `window`, если `bike` есть без окна, **и** выравнивает `fireAt` / `when` виджета (и незакрытого случая). Иначе чип 19:00, пуш со старого часа.
- Закон кладёт карточку срыва в `projection.today`; крышка её рисует. «ничего на сегодня — и это нормально» только если **видимый** Сегодня пуст (карточка считается). Секции Lifetime / Soon / Postponed: сначала `WidgetType.showsOnLid`, без retired, без субъекта живой карточки. Заголовок только при непустом видимом списке. `tileCellSize` только у counter / tick / reminder — `EmptyView`+размер занимает клетку.
- Версия: `MARKETING_VERSION` `0.1.0` в `project.yml`; `Info.plist` берёт `$(MARKETING_VERSION)`, не зашивать `1.0`.

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
