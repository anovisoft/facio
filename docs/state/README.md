## Мины, которые саммари сожмёт

- RFC не переписывать. Eng-правда только здесь. Архив и Expo не воскрешать.
- Закон общий: Swift гоняет `packages/domain/fixtures`. Расхождение — дыра релиза. Посев на Сегодня; в фикстурах те же id лежат в Lifetime — так и должно быть.
- Живая подсказка на отжиманиях: «держи корпус и ягодицы», не английская лекция из фикстуры.
- Лесной зелёный из Expo — запрещён как акцент. `AccentColor` системный.
- Тема следует системе. Светлая атмосфера + dark = белый текст на светлом и моргание шторки. Атмосфера — слабый градиент (не плоская заливка) в `containerBackground(for: .navigation)` плюс копия за стек; `.allowsHitTesting(false)`. Не класть как `.background()` на `NavigationStack`: непрозрачный хром (моноцвет) и мёртвый первый запуск (пустой фон или UI без хитов). Склад через `@State` factory (`DeskStore.live()`), не создавать в `App.init`.
- Liquid Glass включён. Стекло без пятен на фоне не читается. **`GlassEffectContainer` только для кучки кнопок Use (−/+).** На крышке каждая плитка со своим стеклом: общий контейнер сливает ряд велосипеда и два квадрата в одну T-кляксу.
- Плитка: весь квадрат открывает Use (`contentShape` на `.plain`). Галочка на крышке — символ 36pt **overlay рядом** с `FacioTileButton`, не `Button` внутри кнопки (тап молчит или срабатывает дважды). Стекло на стекле снаружи делает круг невидимым. Soon / Postponed — без живых тиков; тап → **Inspect**, не Use.
- Use счётчика: − / + / Готово всегда на месте (стеклянная капсула, не подпись). Готовый случай плюс/минус возвращает в running. Use галочки — символ 44pt, не круг-герой.
- Use: системный бар, не прятать back. Свайп от края = назад. Свайп в другой день посреди подхода запрещён. Кастомное «Назад» + `navigationBarBackButtonHidden` убивает жест.
- Напоминание: час из окна, не из модели. «зал до 22» → `window_from_closing` → 19:00. Назвали час («в 19») — `latest_by` как сказали, даже если рядом «до 23» (не 20:00). Пуш локальный, тап → крышка, не Use. **`opens_at` в схему не добавлять**; пол пикера 06:00…`closes_at`.
- Use часа (принято PO): чип «успеть к 19:00» из склада + `@State` после сейва. Тап → нижний sheet ~340pt, колёса 128×196, **Сохранить** у нижнего края, без заголовка в sheet, фон системный. «Готово» на Use закрывает случай, не пикер. Нельзя: `DatePicker` (binding мёртвый / `.constant` не обновляется), `.disabled` (серый, без хита), `.clipped` на колесе (selection остаётся 19:00), `.fitted` (fullscreen), `.medium` / пустой 320 (дыра), второй `AtmosphereBackground` в sheet, inline-колесо под текстом. Писать `ClockTime` из `@Observable` draft колбэком родителя. Склад — один `commit` (`snapshot = next`). **`generation` удалён, не возвращать.** Окно субъекта пишется и после done.
- Плитка велосипеда как остальные: кебаб, заголовок `.primary`. Слот **4×2** (`wide`), не banner 4×1 — ряд в одну клетку заезжает на соседа. Старый `4x1` поднимает `ensureBike`. Плитки клипаются по слоту пака.
- Крышку, тему и рот не отдавать ферме. В Task вписывать скилы по имени.
- Полир только по списку PO. Клин UI принят как гипотеза. План волн В1–В3 принят PO (2026-08-20). **В1.4 принят PO**; микро UI не чинить, пока PO не даст список. **В1.6:** болтать можно; запись без tool — баг. `run_turn` один nudge, если первый complete без tools. `pytest -m live` / `--live`. **В2.1–В2.3 в коде.** В2.3 без акцепта PO. Не В3.
- Карточка срыва (принято PO): не Use и не кебаб. Чипы только вниз. Не «постарайся». Пока карточка на экране, плитки этого субъекта прячутся. `stop` не рисуем. Ответ один раз на период ритма. Чипы внутри стекла плитки — системные капсулы, не glass-on-glass. Высота 32, ширина по тексту до 152, дальше многоточие; ряд переносится. Нельзя: `maxWidth: .infinity`, `.controlSize(.large)`, равная ширина на всю карточку (текст режется, кнопки на полкарточки). `visibleToday` не должен звать хелпер, который снова читает `visibleToday` — бесконечная рекурсия, краш при старте.
- **Лестница срыва (R4, Q28) — принята PO** (ночь 2026-08-30, после разбора расхождения мины и Q28). Три чипа сразу (сегодня / раз в неделю / убрать) сняты: ступень выбирает закон, карточка рисует **одну** — «сегодня», потом «раз в неделю», потом «убрать» — плюс «не сейчас». Иначе лестницы нет: человек берёт «убрать» на первом же ходу. Вёрстку чипов не трогали. Состояние лестницы — поля **на субъекте** рядом с `paused_at` (`drift_asks_made`, `drift_retire_refusals`, `drift_asked_at`); словари `drift_asks` / `drift_asked_at` на столе сняты, старый `desk.json` их читает один раз и сворачивает в субъект. Два отказа от «убрать» → `stop`: ритм становится `none`, карточка не приходит больше никогда, практика живая в Deeds («no cadence / at hand»). Право спросить и ступень считает `DriftLaw` / `facio_domain.drift`, не модель (never-do AI #10).
- **Группа занятий одного дня — одна плитка (R16, Q34).** Занятия одного субъекта внутри периода несут общий `group_id` (поле было объявлено и мертво), крышка рисует группу **один раз**: ближайший ещё не прошедший час крупно, `3/7`, ряд отметок с часами. **Отметки независимы**, указателя нет: отметил 15:00 — пропущенные 10:00 и 12:00 остаются видимо пропущенными. Степпер это не трогает, он про такты внутри одного занятия. Размер `4×2`, `tileCellSize` ставится на ячейке `LidFeed`, а не наследуется от `tile_size` участника; отметки — overlay-sibling, как у галочки. Группа заводится только при `>1` за день: практика раз в день `group_id` не получает, поэтому старый стол не меняется. Часы раскладываются по занятиям, **только если** окно называет ровно столько часов, сколько занятий — иначе мы решали бы за человека, какая проверка когда.
- **Закрытое занятие группы держит свой час (`GroupLaw.closingStamp`), а не «сейчас»** — иначе отметка в 15:42 переставляет случай и следующая досыпка раздаёт часы в другом порядке.
- **Ответ на nudge — это ответ не человеку.** `run_turn` после текстового первого хода дописывает служебный nudge; если второй ход не сделал записи, наружу идёт **текст, написанный до nudge**. Без этого человек получал «Понял, жду твою просьбу» или лишний `set_reminder` вместо ответа на свой вопрос. Именно это PO видел на телефоне как «Напомню в эти семь часов».
- **Одна практика — одна карточка (R17).** Если у субъекта есть группа этого дня и её отметки уже несут **те самые часы окна**, виджет напоминания **не рисуется** на крышке: группа говорит и ближайший час, и все остальные, а две плитки об одном — второй склад (P10). Проверка именно «группа уже это говорит» (`GroupLaw.saysEveryHour` / `says_every_hour`), а не «группа есть»: часы ложатся на занятия, только когда окно называет их ровно столько, сколько занятий (R16) — иначе часы живут **только** на напоминании, и его нельзя прятать. Правило живёт в проекции (`lid_projection` / `LidProjectionLaw`), берёт группу по ключу **сегодняшнего** дня и требует `total > 1`. **Виджет не удаляем и не архивируем.** `ReminderScheduler.alarms(from:)` читает снимок стола, а не проекцию (оба call site передают `snapshot`), поэтому число и часы будильников не меняются — тест на это обязателен. Утренняя дельта считается по столу до скрытия: спрятанная плитка не должна будить карточку, на которую она же и отвечала.
- **Развёрнутый чат кебаба — одна поверхность (R18).** R11 оставлял панели разговора собственную обводку, скругление и внешние отступы на всём пути наверх, и в конце получалась шторка на шторке. Теперь свёрнутая панель — карточка 3:4 как была, а развёрнутая **перестаёт быть карточкой**: стекло, обводка и радиус гаснут, карточка ложится вровень со шторкой (`cardRect` = весь `geo`, без верхнего отступа), шапка отбита от ручки шторки на 18pt. Хром гасится **`ViewModifier` c `Animatable`** (`SurfaceMerge`, `animatableData`) — с обычного `Bool` обводка и радиус пересчитывались бы один раз и прыгали в конце жеста; и тратится он на **первой половине** движения (`1 - progress*2`), иначе на полпути посреди шторки стоит вторая поверхность. `nonisolated var animatableData` — иначе `conformance ... crosses into main actor-isolated code`.
- **Часы группы правятся из карусели (R18, Q34).** После R17 напоминание с крышки спрятано, поэтому карусель кебаба — **единственное** место, где человек может поправить час. `+` на сгруппированной практике **спрашивает час** тем же нижним листом с колёсами, что принят на Use (`ReminderTimePickerSheet` вынесен из `ReminderUseView.swift` в свой файл, второй пикер не заводить); слот можно переставить на другой час и убрать вместе с занятием; закрытое занятие не двигается и не удаляется. `DeskStore.addInstance` теперь **отказывает** сгруппированной практике — это он ставил «сейчас» и клал два «11:42» подряд. Замок: **часов в окне ровно столько же, сколько занятий**, поэтому час приходит вместе с занятием **и с ритмом** (`cadence.count`), а уходит втроём; иначе R16 перестаёт раскладывать часы и R17 возвращает вторую плитку. Порядок «какому занятию какой час» решает один код — `SeedFactory.ensureOccurrences`, который гоняется после каждой правки (`OccurrenceHourLaw.settle`). Час, уже стоящий в окне, не дублируется (окно идемпотентно) и не даёт второго занятия; переезд на занятый час отклоняется. Последний час не убрать (`TimeWindow.removeHour` отказывается опустошать окно). Будильники — через `commit(reminders: true)`, окно меняется → `ReminderScheduler.enqueue` пересчитывает. Правило живёт только в Swift: рот в этом не участвует, `apps/api` не трогали.
- **День переносится на завтра (R19, Q34).** Дыра R16, найденная на R18: `occurrenceTemplate` искал виджет, привязанный к случаю **этого** дня, на новом дне таких нет, и досыпка писала ноль занятий — вся конструкция жила один день. Теперь **шаблон переживает смену дня**: сегодняшнего виджета нет → берётся самый свежий не-reminder, не-`archived`, `showsOnLid` виджет практики **любого** дня, и с него делается новое занятие; переносится **лицо**, не состояние (`InstanceLaw.resetPayload`). Перенос предлагается **только практике, которая обещает больше одного в день** (`SlotLaw.occurrencesPromised > 1`): у практики раз в день своя перепривязка стоящего виджета, копия оставила бы ей две плитки и переписала бы старый стол. `group_id` нового дня — новый (ключ несёт дату), часы раскладываются тем же правилом R16. **Вчерашние занятия не трогаем вообще:** ни дат, ни статусов, ни закрытых — пропуск остаётся пропуском на своём дне, срыв и дельта его считают. Но **день, который кончился, уходит с Сегодня**: `LidProjectionLaw.belongsToAClosedDay` / `lid.belongs_to_a_closed_day` не рисует виджет с чужим `group_id` — иначе две плитки одной практики (R17) и вчерашние промахи молча переезжают на сегодня. Это правило **рисования**, стол не меняется, карусель их по-прежнему держит; виджет без `group_id` (весь стол до Q34) не задет. Будильники: `SeedFactory.rollAlarm` переставлял `fire_at`/`when` на сегодня сгруппированной практике — **снят в R20**, день больше не берётся со штампа.
- **Напоминание звонит по ритму, а не по штампу (R20, Q7/Q21).** Дыра, оставленная R19 открытой и замеренная: `ReminderScheduler.alarms` брала день из `fire_at` **самого виджета**, а его никто не переставлял одиночной практике — велосипед со стола дня N давал 1 будильник в день N и **0** в N+1, N+2, N+7 (сгруппированная практика жила только за счёт `rollAlarm`). Теперь **день — вывод из ритма**: `SlotLaw.dueDays` по ближайшим `ReminderScheduler.horizonDays` полосам того же `SlotLaw.horizon`, что рисует календарь 7 дней (второго счёта дней не заводить).
