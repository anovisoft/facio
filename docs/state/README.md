# Состояние реализации Facio

Рабочая память для кода и новых сессий.  
Продуктовая правда — [`docs/rfc/`](../rfc/README.md) (черновик v0.7). Сюда RFC не копируем и не раздуваем.

**Этот каталог не заменяет RFC.** Здесь только стек, инварианты, порядок работ и «где мы сейчас». Если решение меняет продукт — сначала правится RFC, потом эта папка.

Зафиксировано 2026-08-16: remaster на SwiftUI + FastAPI.

## После суммаризации — начать здесь

1. Этот файл целиком.
2. [Решения](./decisions.md) — стек, две цели, что считается впечатляющим, инварианты.
3. [План](./plan.md) — шаг 0 принят; шаги 1–7 не начаты.
4. [Идентичность](./identity.md) — не выдумывать bundle / team.
5. По задаче — RFC: [00](../rfc/00-vision.md) … [07](../rfc/07-open-questions.md).
6. Скил продукта: `.cursor/skills/facio-product/SKILL.md`.

Не эволюционировать `archive/apps` и не воскрешать снятый Expo-клиент. Новый код: `apps/mobile-swiftui`, `apps/api`, `packages/domain`.

**Роли.** PO = человек. Ведущий агент этого чата держит крышку, тему и рот; код этих поверхностей не отдаёт ферме. Субагенты — только ограниченный слой после контракта (закон, эндпоинт, eval, один тип по уже принятому размеру). Модель субагента — **Grok 4.6 High Fast** (`cursor-grok-4.6-high-fast`). В промпт Task **вписать скилы по имени** — mdc их в ребёнка не загрузит.

**Следующее действие.** Шаг 1: Swift-порт закона на тех же фикстурах, затем крышка. Не начинать чат, сервер записи и сковородку.

```bash
pip install -e packages/domain

```

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
