## Мины, которые саммари сожмёт

- RFC не переписывать. Eng-правда только здесь. Архив и Expo не воскрешать.
- Закон общий: Swift гоняет `packages/domain/fixtures`. Расхождение — дыра релиза. Посев на Сегодня; в фикстурах те же id лежат в Lifetime — так и должно быть.
- Живая подсказка на отжиманиях: «держи корпус и ягодицы», не английская лекция из фикстуры.
- Склад шага 1: `desk.json` + `journal.jsonl` в Application Support. SQLite — когда синк.
- Лесной зелёный из Expo — запрещён как акцент. Цвет — `primary` / `secondary`. Tint только если несёт смысл. `AccentColor` — системный, не зашитый зелёный.
- Тема следует системе. Светлая атмосфера + тёмная схема = белый текст на светлом и моргание статус-бара. Атмосфера — слабый градиент, не плоская заливка. Класть в `containerBackground(for: .navigation)` и копией за стек; `.allowsHitTesting(false)`. Не класть как `.background()` на `NavigationStack`: iOS 26 рисует непрозрачный хром сверху (моноцвет) и на первом запуске может перекрыть хиты — пустой фон или живой вид без отклика, лечится только перезапуском.
- Liquid Glass включён (PO). Стекло без пёстрого фона не читается — `AtmosphereBackground` обязан давать пятна. Плитки и кнопки Use в `GlassEffectContainer`. Ниже iOS 26 — materials.
- Плитка: весь квадрат открывает Use (`contentShape`). Шапка работала, тело — нет: `.plain` бьёт только по непрозрачным пикселям. Галочка на плитке — символ 36pt внутри плитки. Стекло на стекле снаружи плитки делает круг невидимым.
- Use счётчика: − / + / Готово всегда на месте. Готовый случай плюс/минус возвращает в running. Use галочки — символ 44pt, не стеклянный круг-герой.
- Use: системный бар, не прятать back. Свайп от края = назад. Свайп в другой день посреди подхода по-прежнему запрещён.
- Кастомное «Назад» + `navigationBarBackButtonHidden` убивает жест — больше так не делать.
- Крышку, тему и рот не отдавать ферме субагентов. В Task вписывать скилы по имени.
- Рот — часть клина (витрина + чужой человек), но не до закрытия шага 1 по вкусу и не вместо шагов 2–3.
- Список «доработать сразу» (2026-08-16): шторка; контраст; клик по плитке; кнопки Use; размер галочки Use. Добивка: галочка на крышке пропала; фон стал моноцветом; первый запуск после сборки мёртвый. Закрыто в коде, не в вкусе PO.

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
