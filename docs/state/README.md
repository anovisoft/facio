Субагенты — только ограниченный слой после контракта (закон, эндпоинт, eval, один тип по уже принятому размеру). Модель субагента — **Grok 4.6 High Fast** (`cursor-grok-4.6-high-fast`). В промпт Task **вписать скилы по имени** — mdc их в ребёнка не загрузит.

## Как гонять сейчас

```bash
# Закон
python3 -m venv packages/domain/.venv
source packages/domain/.venv/bin/activate
pip install -e packages/domain
pytest packages/domain

# Крышка
cd apps/mobile-swiftui
xcodegen generate
xcodebuild -scheme Facio -destination 'platform=iOS Simulator,name=iPhone 17' test
open Facio.xcodeproj
```

## Одна фраза

Facio даёт совету тело: вывод из разговора возвращается сам, в нужный день и час, с причиной. Материализовать ответ один раз — вход. Вернуть его с причиной — продукт.
