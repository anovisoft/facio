# Автономный прогон к RFC-like (ветка `rfc-run`)

Запущен 2026-08-29 по решению PO: «попробовать автономно подойти к RFC-версии, с английским,
без постоянного участия». PO дал в чате четыре решения:

1. Скоуп: сначала волна **E** (английский до конца), потом закрывать разрывы до RFC.
2. Парковки PO (кебаб 3×4, postpone/delete, реальные Настройки, полир шторки) — **распаркованы**
   как часть цели «дойти до RFC».
3. Ветка `rfc-run`, автокоммит **каждого зелёного среза**. В `main` не лить, на remote не пушить.
4. Live-прогоны рта на ключе Anthropic — **можно на каждой волне рта**.

PM = ведущий агент. PO акцепта здесь нет ни у одного среза: всё в ветке, ждёт чтения.

## Разрыв до RFC на входе

- **Английского нет.** `Localizable.xcstrings`: `sourceLanguage: ru`, 79 ключей, `en` у 4.
  `SYSTEM_PROMPT` русский, `match_golden` матчит русские подстроки. Симулятор с кириллицей
  не тестируется руками — английский нужен как механизм проверки, не только как цель.
- Каталог виджетов: `checklist` / `timer` / `stepper` отбиваются `unsupported_widget_type` (Q1).
- Кебаб урезан: нет 3×4 миниатюры чата, нет postpone/delete (03-product).
- Q31/Q32: выделение фразы → `clarification` cue и `?` на шаге — нет.
- Q28 лестница срыва (три ступени, раз в период, стоп после двух отказов) — нет. Q6 дельта-утро — нет.
- Q33 media-link на cue — нет. Замеры (шаг 7) — нет.
- Настройки — подпись «позже». `m2-m3` (Sign in with Apple, синк стола) лежит в коде **не подключённым к UI**.

## Чего этот прогон не сделает

APNs и облачный пуш (нет сертификатов и живого устройства), включение capability
Sign in with Apple в портале Apple для Team SXXLPXXJMD, акцепт PO.

## Что вскрыл живой прогон (не чтение кода)

1. **Практика из рта — не практика.** «put the gym on the desk» создаёт субъект `gym` с
   `cadence: none`, без подсказки и без цели; плитка читается «gym 0 / 0». RFC 06 never-do #14:
   тип без ритма, do-time подсказки и срыва — не этот продукт, а слабый планировщик. Дыра
   зафиксирована золотыми **в обеих локалях** — то есть это не промах модели, это наш контракт.
   RFC 05 прямо относит «превратить намерение в субъект **с ритмом**» к работе рта, а Q11 разрешает
   поставить черновую плитку и спросить **после** записи. Следующий срез.
2. **Рот цитирует собственное правило.** Ответ «The gym is on the desk. No hour: you did not ask
   for one» — первый замок промпта запрещает пересказывать правила и умолчания человеку.
   Русская золотая страдает тем же. Правится вместе с пунктом 1.
3. **Симулятор печатал кириллицу на ASCII** — активной была русская раскладка. На устройстве
   оставлена только `en_US`; без этого прогонять крышку руками нельзя вообще.
| E2b | Отказ инструмента называет поле (`invalid_kind` / `invalid_surface`) — ход чинит себя следующим раундом; умолчание субъекта при «боль + пропуск» дописано симметрично в обе языковые половины | domain 86 passed; api 120 passed / 20 skipped; live 5×2: RU «напомни в 19» 3/5→4/5, EN «skipped today, my back hurt» 4/5→5/5 | коммит `030ee98` |
| R0 | Ритм обязателен при создании новой практики (`cadence_required`, той же формы замок, что `surface_required`); метод пишется как `correction`/`do-time`; из 10 золотых убран пересказ собственных правил человеку | domain 97 passed; api 170 passed / 20 skipped; live 5×2: «запиши зал» 0/5→5/5, «могу 4, хочу 30» 4/5→5/5 | коммит ниже |
