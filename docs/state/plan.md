# План реализации

Порядок из RFC (вопрос 23), уточнённый сессией 2026-08-15.  
Продуктовые фазы клина — в [00](../rfc/00-vision.md). Здесь — инженерные шаги.

Правило: не прыгать через шаг без явной причины. Чат и сервер не начинают, пока клин не прожил на человеке.

---

## Шаги

### 0. Закон

**Зачем.** Арифметика до пикселей.

- Модели: практика, подсказка, случай, виджет, ритм, окно.
- Чистые функции: срыв, проекция крышки, время напоминания.
- Фикстуры основателя: отжимания, велосипед, овощи; пороги срыва из вопроса 27; лестница из вопроса 28.
- Подсказка без места показа — отказ.
- Выгрузка JSON-схемы.

**Не входит.** Сеть, экраны, модель.

**Готово когда.** Проверки зелёные: велосипед `2×/неделя` и 8 дней тишины = срыв, 6 дней = нет; пустой сегодня без обязательств ≠ пустой сегодня со срывом.

### 1. Крышка на устройстве

**Зачем.** Фаза 0 зрения: одна практика держит причину.

- Новое Expo-приложение. Дом — крышка, одна лента сверху вниз.
- Склад на устройстве. Сразу журнал событий, не только снимок виджета (иначе потом не посчитать попадания и не свести синк).
- Заготовка руками, не чат: отжимания `3×/неделя`, цель 30, подсказка «корпус и ягодицы»; овощи «почти каждый день».
- Счётчик на сегодня: число и подсказка на плитке в момент дела.
- Галочка на сегодня.
- Нажатие — полный экран «делай», без карусели и без чата.
- Сетка в четыре колонки, упаковка простая: по рангу, дырки можно, плитки не переставлять ради плотности.

**Не входит.** Поле разговора, сковородка, напоминания, сервер, список практик.

**Готово когда.** Открыл → видишь отжимания → на первом повторе читается подсказка. Автор может так жить, дописывая случаи пальцем.

Это единственный шаг, который имеет право называться «есть продукт».

### 2. Напоминание и окно

- Практика «велосипед», подсказка времени «зал до 22» → окно «успеть к 19:00».
- Локальное уведомление из объекта напоминания, не из модели.
- Нажатие ведёт на крышку (или на просмотр этого объекта, если экран уже есть).

**Готово когда.** В семь вечера, не в без десяти десять. Модели на срабатывании нет.

### 3. Срыв и утренняя карточка

- Утро: сдвиг или срыв → максимум одна карточка на сегодня.
- Чипы срыва: сегодня / раз в неделю / убрать.
- Лестница вниз, не громче, один раз за период ритма. После двух отказов убрать — перестать спрашивать, практика остаётся в списке без ритма.
- Пустой сегодня без срыва остаётся пустым.

**Готово когда.** Критерии остановки из RFC можно проверить на живой неделе.

### 4. Узкий разговор, потом полный чат

Сначала узкий write, не мессенджер.

**Узкий (можно в тот же клин, что шаги 1–3):**

- На виджете правка пальцем — обязательно.
- Одно поле «сказать про это» у выбранной практики.
- Модель возвращает только: добавить подсказку / сменить цель / сменить ритм / уменьшить. Нет места показа — отказ. Боль — нельзя поднять цель или ритм.
- На экране: живая плитка и одна строка подтверждения.

**Полный чат (только после живого клина):**

1. Стенд золотых реплик → ожидаемые вызовы и конечный стол. Не украшение.
2. Сервис: ход в текущий тред, поток текста и событий.
3. Инструменты ровно из [05](../rfc/05-ai-and-memory.md).
4. Поле на крышке открывает текущий тред. «Новый чат» сверху листа. Свернуть — не сбросить.
5. Смена схемы — живая плитка и снимок по центру. Только объяснение — текст. Палец на крышке — без карточки.
6. Выделение фразы → пояснение и подсказка на шаг (цитата текстом, не позиция в сообщении).
7. Политика боли до инструментов, не «пожалуйста» в промпте.

Склад на этом шаге ещё может быть только на устройстве. Сервис принимает снимок стола и возвращает проверенный патч. Вход и база не обязаны ехать в том же спринте.

**Готово когда (узкий).** «Поясница забирает» → подсказка на отжиманиях, плитка живая.  
**Готово когда (полный).** То же плюс новый чат, снимок, второй человек может получить пояснение и знак вопроса на шаге.

**Не входит.** Голос, поиск по сырой переписке, библиотека медиа, глубина степпера.

### 5. Сковородка, список практик, просмотр

- Жест от левого края — сковородка: разговоры, практики, настройки. На полном экране левый край — назад, не сковородка.
- Меню плитки: карусель случаев во времени, миниатюра чата, прокрутка к главе (глава считается, не хранится как сущность).
- Делать ≠ смотреть. Горизонтальный свайп только в просмотре.
- Плюс создаёт новый случай.

**Готово когда.** Велосипед повторяется из списка практик, не из воскрешённого гайда. Экран «делай» не свайпается вчерашним днём.

### 6. Сервер записи, вход, синк

Проектировать, не ставить одну перезапись на весь виджет.

| Канал | Примеры | Спор |
|-------|---------|------|
| Структура | содержимое, тип, ритм, текст подсказки, версия | побеждает поздняя версия |
| Прогресс | галочки, текущее число, время таймера, шаг | слияние по элементу; структурная запись не имеет права стереть |

Вход — настоящие счета до синка на несколько устройств. Идентификатор устройства не продлевать в прод.  
Фото на подсказке — первый двоичный груз: сначала на устройстве, молча не подменять.

### 7. Измерения

Не сумма из головы. Считать:

- доля подсказок, которые показали и применили (без журнала не существует);
- срыв всплыл за один период ритма;
- практики живы на четвёртой неделе;
- доля разговоров, которые кончились механикой, не только текстом;
- цена за активный день (токены только на разговор и одну утреннюю строку).

Платный тариф не открывать, пока нет числа. Подсказку и напоминание не прятать за оплату — это и есть продукт.

## Клин на двое суток

Не семь шагов подряд. Один вертикальный кусок, на котором можно жить.

**День 1**

- Закон и проверки.
- Пустое приложение, дом — крышка.
- Две практики из файла.
- Счётчик с подсказкой на плитке.
- Галочка.
- Полный экран «делай» без листания вчера.
- Рукой правится подсказка и цель.

**День 2**

- Окно → локальное напоминание.
- Карточка срыва с тремя чипами.
- Одно поле разговора, только безопасный патч.
- Сервис, вход, синк, сковородку не открывать.

Дальше не «докодить оставшиеся шаги», а две недели жить. Если зайдёт второй человек сразу — узкое поле в день 2 обязательно. Если только автор — хватит правки пальцем.

После выходных честно говорить: есть клин, нет полного чата и нет сервера.

## Кто чем владеет

| Слой | Пока живём на устройстве | Когда появится синк |
|------|--------------------------|---------------------|
| Схемы | питон + типы на клиенте | то же |
| Расчёт срыва, крышки, часа | проверки на питоне + тонкий порт на клиенте | питон — источник, клиент кэширует |
| Рантайм виджета | только телефон | только телефон |
| Узкий / полный разговор | нет или удар из телефона | сервис |
| Напоминания | системные, локально | локально; рассылка с сервера только если локальных мало |
| Правда о состоянии | склад на устройстве | база; крышка читает кэш, чтобы делать без сети |

## Журнал событий (заложить в шаге 1)

Писать сразу, не «текущий JSON виджета как единственную правду»:

- подсказку записали / показали / применили;
- случай начали / закончили;
- число счётчика, прошедшее время;
- практику уменьшили / убрали.

Попадания и поздний синк читают тот же журнал.

## Риски, которые уже названы

| Риск | Ответ в коде |
|------|----------------|
| Открытая практика («построить проект») | случай = следующий конкретный шаг. Не строить карту на месяцы, пока не сработали три коротких физических. |
| Метод выдан и не понят | знак вопроса на каждом шаге; одна проверка после первого раза; видео по ссылке или своё фото, не каталог. |
| Боль как параметр | заслон до инструментов: нельзя поднять ритм или цель, если в ходе есть боль. |
| Два языка разъедутся | одни фикстуры гоняются и там, и там. Расхождение — дыра релиза. |
| Сначала красивый чат | полный чат не стартует, пока клин не прошёл критерии остановки на авторе. |

## Явно не в этой работе

Чертёжный язык, экономика намерений, биллинг тренера, соцсеть, «любая цель», клон дневника тренировок, готовка как клин, голос как первый вход, поиск по сырой переписке как память.
