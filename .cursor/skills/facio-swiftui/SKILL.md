# Facio SwiftUI

Before writing views, read:

1. This file
2. `.cursor/skills/facio-product/SKILL.md`
3. The SwiftUI expert skill (`swiftui-expert-skill`) and, for review, `swiftui-pro`

## App

- New app at `apps/mobile-swiftui`. Identity from [`docs/state/identity.md`](../../../docs/state/identity.md): `Facio`, `com.anovisoft.facio`, team `SXXLPXXJMD`, iOS 18+, portrait, no iPad.
- No third-party UI kits unless PO asks.
- Liquid Glass is on (PO, 2026-08-16): tiles and Use controls. `#available(iOS 26)` with material fallback. `GlassEffectContainer` is for a tight control cluster (Use −/+), not the lid pack — the container morphs neighbors into one blob. Lid tiles each carry their own glass. Do not invent a brand-green accent — semantic `primary` / `secondary`, tint only for meaning.
- Theme follows the system. Atmosphere is a weak gradient (not a flat fill) via `containerBackground(for: .navigation)` plus an inert window-level copy. Atmosphere never hit-tests. Whole tile opens Use (`contentShape` on the glass), not only the title row. Counter Use keeps − / + / Готово after done; tick Use uses a normal 44pt checkbox, not a hero circle. Lid tick mark is a **36pt symbol** inside the tile, as an **overlay sibling** — never a `Button` nested in `FacioTileButton`, never glass-on-glass. Soon / Postponed are glance-only (`action: nil`). Hollow stubs for checklist / timer / stepper do not occupy pack cells.
- Reminder is a **wide 4×2 row** (not 4×1): title + time + cue need a compact-tall slot or the card paints over the next tile. Matches other tiles: kebab, `.primary` title. Fire time is `ReminderClock` from the subject window, never the model. Local notification; tap opens the lid, not Use. `DeskStore.commit` replaces the whole snapshot once; `ReminderScheduler.enqueue` only on reminder writes (not on −/+) **and on launch** — `sync` is not a public bypass. Overlapping enqueue coalesces — an older wipe/re-add must not resurrect a completed alarm. `markCueSurfaced` once per widget+place+day from the journal, not only RAM; `onAppear` on a recycled tile must not increment again. On Use the time is a live chip from `store.windowFor` (not a compact `DatePicker` + `.constant` — that chip never redraws after save). Tap opens a **~340pt bottom sheet**: two wide `Picker` wheels (128×196, finger-sized) with a colon; **Сохранить** pinned to the bottom of the sheet, not mid-card. No title in the sheet (Use already says «успеть к»). No `DatePicker`, no `.fitted` / `.medium` / 320pt void, no second `AtmosphereBackground` on the sheet. The sheet commits `ClockTime` through a parent callback onto an `@Observable` draft (not `DatePicker`, not `.clipped` on the wheel — both drop the selection). The Use chip keeps the saved clock in `@State` so it updates even if Observation is late. Do not poke a `generation` counter. Do not expand a wheel inline. Range is gym hours: default open 06:00 … `closes_at`. Do not invent `opens_at` in the schema. Use **Готово** stays the glass capsule that completes the reminder. `ensureBike` backfills a missing `window` on an existing bike subject and realigns `fireAt` / `when` to that window. `ensureDrift` adds a 21-day completed instance only when the bike has no activity, and moves the seed tile to Lifetime so Today can show the card.
- Drift card is a Today tile, not Use: copy + **one** downward chip from `DriftLaw.nextOffer` (сегодня → раз в неделю → убрать) plus «не сейчас». Never “try harder”, and never all three rungs at once — that is not a ladder. Chips hug their text (PO, 2026-08-16): height 32, width up to 152 then ellipsis — not equal-width, not `controlSize.large`, not `maxWidth: .infinity`. Capsules wrap to the next line if the row is full. Chips inside the glass card are system capsules, not glass-on-glass. While the card is surfaced, hide that subject’s widgets. `stop` is not drawn. Ladder state is three fields on `Subject` next to `pausedAt` (`driftAsksMade`, `driftRetireRefusals`, `driftAskedAt`) — no side table on the desk. Answering or refusing stamps `driftAskedAt` and hides the card for one cadence period; two refusals of «убрать» drop the cadence to none and the card never returns, with the practice alive in Deeds. Retired subjects drop reminder alarms. `MorningLaw` adds the delta line (Q6): drift wins, otherwise one calm chip-less card for a practice that owes this period and has no live Today tile — never for one that has never run. Still no morning notify hour. Empty Today copy only when **visible** Today is empty (surfaced card counts). `visibleToday` must not recurse through a helper that reads `visibleToday` again.
- Localize via `String(localized:)`. User-facing copy may be Russian; identifiers stay English and match the RFC (`Subject`, `Cue`, `Widget`, `surface`).

## Law on device

Port `packages/domain` as pure functions. Drive tests with `packages/domain/fixtures/*.json`. A mismatch with Python tests is a release hole. Do not invent a second drift or packer.

## Surfaces

- Home is one vertical lid feed. No bottom tabs. No horizontal section paging.
- Type owns tile size on a 4-column grid. Pack row-major in rank order; gaps allowed; never reorder to fill holes.
- Today / Lifetime tiles may be lightly interactive. Soon / Postponed are glance-only (no live ticks); tap opens **Inspect**, not Use.
- Use: do now, no instance carousel. Inspect: instance chips + loud date, look-only. Left edge on fullscreen is back, not pan.
- Pan (сковородка) sits **under** the lid and slides it right. Open only from **lid root**: leading ☰ and a ~20 pt left gutter. Off when the keyboard is up. Off on Use/Inspect — that edge is system back. Do not put the gutter on `NavigationStack` or Use. Talks (archive) and Deeds live in the pan; Settings is a footer stub. Opening a Talk opens that thread’s sheet (not a chat-home). Deeds opens the kebab inspector. `PanHost` uses `PanSlideLayout`: the lid is **placed** at `x = revealed` with the **container** size. Closed (`revealed == 0`) the lid is the full screen. Never `HStack` + `offset(-panWidth)`. Never `safeAreaPadding(.leading)` on the lid stack to “restore Facio” — the bar drops its inset and the whole feed glues to the cut; the composer survives only because it has its own padding. «Facio» is a `.largeTitle` in the lid scroll with `pagePadding`, same as the tiles. `facioLidTitle()` keeps `navigationTitle` for the Use back button, inline, principal empty. Do not wrap `NavigationStack` in `GeometryReader`. Dim on the lid only — always present, opacity follows progress. Never `if revealed > 0` (removal uses an opacity transition and the dim stays parked while the lid slides). Do **not** raise pan `zIndex` above the lid. Pan under `ignoresSafeArea`: pad with `WindowMetrics.safeArea`. Round the card with `WindowMetrics.displayCornerRadius` (continuous), radius 0 when closed. `+` on the instance strip creates a new instance (`DeskStore.addInstance`): clone a Today tile when the live widget still occupies Today (ready/running or done-today); otherwise rebind a standing/lifetime widget onto Today.
- Kebab is an overlay sibling (`facioKebab`), never a `Button` inside `FacioTileButton`. Long-press on the tile opens the same inspector; tap still opens Use/Inspect (long-press must not also fire the tap). Inspector: chips, Open → Inspect, talk miniature. No full-screen `TabView` pager — it fights the back gesture.
- Composer docks on the lid (and on Use — PO), **not on Inspect**. Apply `facioComposerDock()` on **LidScreen and UseScreen**, not on `NavigationStack` — a stack inset does not lift pushed Use, so «Готово» sits under the dock. Tap the dock (not an inline TextField) to open an almost-fullscreen chat sheet (`presentationDetents` ~0.94, drag handle). Collapse hides; it does not start a new thread. **New chat** is the trailing toolbar item on the sheet. Placeholder: «Что сюда на стол?» — not “ask anything”. Sheet field is a single-line `TextField` centered on the send button; do not use `axis: .vertical` (UITextView sits the prompt below the pill’s midline). Empty 44pt slot to the right of the dock is reserved for voice; no mic button. Human bubbles trailing, assistant leading, widget **snapshot centered** (a picture: title + line, not a runtime). Structural change → live tile + snapshot in this chat. Explain-only → text, no card. Talk hits `FacioTalkURL` (`http://127.0.0.1:8000`); the model key never leaves the server. If the pipe is down, the lid still ticks. Do not put `AtmosphereBackground` on the talk sheet. Pan Talks is the archive list, not the home and not the sheet. `TalkStore` owns threads (`talks.json`); `open(threadId:)` promotes an archived thread to current. `DeskStore.applyTalk` takes `toolCalls`: keep local `.running` `payload.count` unless a successful `update_widget` / `create_widget` named that widget; then `commit` once. Micro UI nits after В1.4 PO accept are parked — do not polish unless PO lists them.
- Chat cards are centered snapshots, not live runtimes.

## Taste

Calm table, not a casino. Prefer native SwiftUI, `@Observable`, small views, `Button` for taps. The lid is the Upwork first frame — default chrome is not enough, decoration for its own sake is not either.
