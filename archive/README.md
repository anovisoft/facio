# archive

The previous incarnation of Facio, kept for reference. **Nothing here is part of the current build.**

An Expo/React Native client and a Python backend that came before the remaster of 2026-08-16. They are
in the repository because the reasoning that produced the current design is easier to follow with the
thing it replaced still visible, not because any of it runs.

The current code is `packages/domain`, `apps/api` and `apps/mobile-swiftui`. Nothing in this directory
is built, tested or deployed, and no CI job touches it.
