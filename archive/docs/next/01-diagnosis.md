# 01 — Диагноз

## Что есть сейчас

Билд в `apps/` закрывает каркас из `mvp/`:

- Intent → gate → soft-start + draft Path
- Refine (фактически по одному вопросу в UI)
- Accept → Home «Сегодня» + why + чеклист
- Multi-project, audit trail

Этого достаточно, чтобы сказать: «техника и воронка работают».

Этого **недостаточно**, чтобы сказать: «продукт нужен».

## Почему нет ощущения ценности

| Сейчас | Ожидание Facio |
|--------|----------------|
| AI-список шагов + why | Программа, которую **ведут** |
| Home = текст + Сделано | Home = рабочий инструмент шага |
| Clarify = вопрос → LLM → снова вопрос | Пакет уточнений, Path живёт на экране |
| `day_offset` почти невидим | День N цикла: train / rest / cook session |
| Нет таймеров / доз | Оркестрация времени и нагрузки |
| Нет продления | Цикл → результат → следующий цикл |

ChatGPT уже умеет «красивый план». Facio выигрывает только как **runtime**: время, доза, ритм дней, ремонт, следующий цикл.

## POC vs MVP

| | POC (сейчас) | Next (этот каталог) |
|--|--------------|---------------------|
| Вопрос | Умеем ли intent→Path→Сделано? | Станем ли пользоваться сами на эталонах? |
| Артефакт | Плоский Path + checklist | Cycle + schedule + plugins + narrative |
| Тест | Внутренний smoke | Dogfood на карбонаре / отжиманиях → потом люди |

`mvp/` не отменяется: emotion beat, Commit после Path, «Сегодня» + why, no chat-home — остаются. Меняется **глубина исполняемого артефакта**.

## Принцип среза

> Plan on create == plan in use (preview vs live).  
> Cycle is first-class.  
> Shared primitives for cooking and training.  
> Repair is part of the slice, not «потом».
