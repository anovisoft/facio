# Network Effects

## Be honest: Facio is not a classic network-effect product

Most value is **single-player**: my project, my plan, my outcome.

Forcing social features early usually harms focus and creates moderation costs.

## Real effects that *can* appear

### 1. Data network effects (weak → medium)

More execution data → better strategies for the next user.

This is a **data effect**, not a viral social network effect. It is slow and depends on governance (see [Data Flywheel](./18-data-flywheel.md)).

### 2. Content / blueprint marketplace effects (later)

Creators publish blueprints → users come → creators earn → more blueprints.

Risks: quality collapse, liability, SEO spam. Gate hard.

### 3. Reputation / brand category effects

Word of mouth in a niche (“pull-up app”) can look like network effects but is really brand + proof.

### 4. Multiplayer accountability (optional, careful)

Buddy checks, coach-client mode.

Only add when single-player loop is strong. Accountability can help retention but is not the core identity.

## Fake network effects to avoid claiming

- “users chat with each other about goals” (you become a forum)
- “social feed of wins” (you become Instagram)
- “invite friends to unlock features” (growth hack ≠ network effect)

## Strategic recommendation

Optimize for **single-player excellence + data compounding**.

Treat social/marketplace as expansion chapters, not founding mythology.

## Critique

If the pitch deck leads with “network effects from 100k intents,” investors who know consumer social will smell confusion.

Lead with outcome attainment and unit economics; mention data compounding second.
