# Future Roadmap

Phased to force learning. Dates are relative; gates are absolute.

## Phase 0 — Foundations (now)

**Outcomes**

- this RFC pack agreed
- wedge domain chosen (recommend: skill/fitness practice loops)
- domain model + schema sketches
- success metrics defined

**Exit gate**

- written decision on wedge + non-goals

## Phase 1 — Vertical slice MVP

**Build**

- intention capture → hybrid bind to OutcomeType
- 15–40 blueprints in one domain family
- intake UI (≤5 Q)
- compiler + scheduler
- next-action home
- reminders
- stall detectors + 5–10 playbooks
- basic analytics events

**AI**

- embeddings + retrieval
- LLM only for ambiguity / residual patches (capped)
- no full Coach yet (or ultra-thin)

**Exit gate**

- time-to-first-action < 24h for majority
- D7 execution rate hits internal bar
- $ LLM / activated user within budget

## Phase 2 — Repair & monetization

**Build**

- AI Coach with tools + patch diffs
- richer repair library
- subscription entitlements
- plan version history / undo

**Exit gate**

- post-stall recovery improves with Coach vs playbook-only
- Plus conversion without hurting free completion
- gross margin on Plus acceptable

## Phase 3 — Second domain + taxonomy maturity

**Build**

- second domain (e.g. cooking short-horizon OR finance micro-goals)
- taxonomy governance tools
- localization pass if needed
- on-device/offline hardening

**Exit gate**

- second domain attainment ≠ collapse of first
- coverage metrics honest in marketing

## Phase 4 — Intelligence compounding

**Build**

- blueprint analytics console
- bandits for repairs
- assisted mining of new OutcomeTypes from failures
- advanced evidence integrations (HealthKit etc.) carefully

## Phase 5 — Platform expansion (optional)

- creator / coach blueprint publishing (gated)
- client-trainer mode
- B2B wellness experiments

Only if consumer retention is real.

## Explicitly deferred

- open-ended life OS for every intention on day 1
- social feed
- marketplace spam
- voice companion
- AR form checks
- autonomous agents booking your life

## Roadmap critique of the original vision

The original vision jumps to “100k intents + self-improving knowledge base.”

That is Phase 4 fantasy if Phase 1 execution is weak.

Sequence ruthlessly: **runtime → repair → breadth → learning → platform.**
