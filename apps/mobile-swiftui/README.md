# Facio (SwiftUI)

Крышка на устройстве. Закон — порт `packages/domain` на тех же фикстурах.

```bash
cd apps/mobile-swiftui
xcodegen generate
xcodebuild -scheme Facio -destination 'platform=iOS Simulator,name=iPhone 17' test
```

Открыть `Facio.xcodeproj`. Bundle `com.anovisoft.facio`, team `SXXLPXXJMD`.
